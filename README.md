# solar-system
Proyek ini adalah template sistem tata surya yang memungkinkan pengguna untuk mengamati bagaimana planet-planet mengorbit matahari.

## Fungsi Utama
Menyediakan template sistem tata surya yang dapat diamati
Memungkinkan pengguna untuk melihat bagaimana planet-planet mengorbit matahari
